# A Day of One-Line Pitches

One-line pitch entry for the make.fun bounty "A Day of One-Line Pitches". The program `main.py` writes a single sentence to `/output/entry.txt` — a warm, plain-words invitation for a friend who has never coded to describe their app idea and let an AI agent build it for them on make.fun, free to try, with no coding needed and full freedom to change anything until it feels like theirs.
